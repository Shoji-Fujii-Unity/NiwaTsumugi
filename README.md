## 1. これは何？

**ブラウザだけで動く単一 HTML ファイルのガーデニング育成ゲーム**です。
`index.html` を開くと庭が始まり、閉じている間も季節は流れ、開いたときにまとめて精算されます。
約 100 年（＝ 2400 日）を過ごすと、その人だけの庭の歴史が **図鑑・交配表・年表・勲章** として積み上がります。

元の『百年庭』から、見た目・手触り・システムの三点を大きく作り直しました。

### 元作からの変更点

| | 内容 |
|---|---|
| 🖼 **画面が「庭」になった** | 空・日差し・雲・遠景の植え込み・畝（苗床）・小道・庭具をレイヤーで描く。季節と時刻で空の色が変わり、夜は星とランタン |
| 🌦 **天気システム** | 快晴／曇り／雨／雷雨／霧／霜／雪。成長速度・水分・折れる花が天候で決まる。**明日の空予報**あり（風見鶏を買うと必ず的中） |
| 🍂 **土づくり** | 畝ごとに土力があり、収穫で痩せる。枯れた株はたい肥に変わり、すき込むと次の株が育つ |
| 🍀 **コンパニオンプランツ** | 相性の良い隣同士（19 種ペア）はよく育ち、悪い組み合わせは伸びる。図鑑の「相性の良い隣」タブに記録 |
| 🧰 **道具** | じょうろの三段階升級、たい肥、寒冷紗（霜から一株を守る）、切り戻し（花期が延びる） |
| 🎐 **できごと** | 花見・蜜蜂・突風・虹・蛍・旅人の値引き・子どの水やり…など 13 種。年表に残る |
| 👁 **今日の庭** | 開いた瞬間に「何が咲いた／誰が渇いた／何が変わった」を一枚で提示。留守が長いときは日誌シート |
| ✋ **ドラッグで植える** | 種袋から苗床へドラッグ（タップでも可）。水やりは粒が落ちて土が濡れる |
| 🔊 **音** | 季節ごとに pentatonic で即興する環境音楽＋風のノイズ＋雨音＋小鳥。Web Audio 合成で音声ファイル不要 |
| 🗃 **保存の強化** | IndexedDB（localForage）を主、localStorage をミラーに。壊れたデータは自動で初期化せず正規化 |
| 🌿 **草花 48 種** | 35 種 + 交配 13 種（牡丹・百合・藤・勿忘草・芙容など追加）。解説文は日英中 |
| ⏱ **庭の速さを選べる** | 本格 3 時間／日〜 今すぐ 6 秒／日。デフォルトは さくさく 5 分／日 |

## 2. 使っているライブラリ（全部ネットから読み込み）

`index.html` の `<head>` から CDN で読み込みます。すべて **存在確認つき**で、読み込めなくてもゲームは成立します（実際にネットワークを遮断して確認済み）。

| ライブラリ | 役割 |
|---|---|
| [PixiJS 7](https://pixijs.com/) | 花びら・紅葉・雪・雨・蛍・木漏れ日などのパーティクル層（無ければ Canvas2D に自動フォールバック） |
| [GSAP 3](https://gsap.com/) | 咲いた瞬間の跳ね、収穫の弾み、水滴の落下などのイージング |
| [Tone.js](https://tonejs.github.io/) | 季節ごとの環境音楽・風のノイズ・雨音・効果音（合成音声／ファイル不要） |
| [SortableJS](https://sortablejs.github.io/Sortable/) | 種袋 → 苗床 のドラッグ＆ドロップ植栽 |
| [canvas-confetti](https://confettijs.org/) | 新種発見・交配・勲章の祝い（花びら風に調整） |
| [localForage](https://localforage.github.io/localForage/) | IndexedDB 保存＋localStorage ミラー |
| [Google Fonts](https://fonts.google.com/) | Shippori Mincho B1（見出し）／ Zen Kaku Gothic New（本文） |

## 3. 始め方

**A. いちばん簡単** — `index.html` をブラウザで開くだけ（初回はネット接続が必要）。

**B. ローカルサーバー**

```bash
# index.html と同じフォルダで
python -m http.server 8080     # → http://localhost:8080
```

**C. 静的ホスティング** — `index.html` を置くだけ。ビルド不要。

> ⚠️ 保存データは **オリジン単位** です。`file://` と `https://…` は別データになります。遊ぶ URL を一つ決めてください。
> 📲 ホーム画面に追加すると全画面で起動できます。

**対応**: ES2020 が動くブラウザ（Chrome / Edge / Firefox / Safari 最新推奨）、`localStorage` 有効。

## 4. 遊び方

1. **植える** — 種袋の種を選ぶ → 空き苗床をタップ（またはドラッグ）。
2. **水やり** — 一日一回で十分。雨の日は不要。じょうろを升級すると全畝・一日二回に。
3. **空を見る** — 今日の空と明日の予報。霜の予報なら寒冷紗、雨予報なら水やりを控える。
4. **咲かせる** — 隣り合う二つが同時に咲くと交配。蕾の時期に図鑑の「交配表」で手がかりを解放できる。
5. **土を育てる** — 枯れた株は片付けてたい肥に。痩せた畝は育ちが悪い。
6. **手入れ** — 切り戻しで花が長もち、コンパニオンで周りが伸びる。
7. **眺める** — 下部の「眺める」で UI が消え、季節の句だけが浮かぶ全画面モード。
8. **百年むかえる** — 百年の記録が詩になり、「次の百年」へ引き継げます（図鑑・年表・勲章は残る）。

**庭の速さ**（設定 → 庭の速さ）

| presets | 1 日 = | 1 百年 ≈ |
|---|---|---|
| 本格 | 3 時間 | 約 300 日（リアル） |
| ゆったり | 30 分 | 約 50 日 |
| **さくさく（既定）** | 5 分 | 約 8 日 |
| 早送り | 45 秒 | 約 1.2 日 |
| 今すぐ | 6 秒 | 約 4 時間 |

## 5. 言語

既定で **日本語 / English / 中文**。ブラウザ言語で自動選択 → 設定で手動切替 → 保存。
図鑑の解説文・年表・四季の句もすべて三言語です。追加は `index.html` 内の `[ui]` 辞書に `key=ja|en|zh` を足すだけ。

## 6. セーブデータ

| 項目 | 内容 |
|---|---|
| 保存先 | IndexedDB（localForage）＋ localStorage ミラー。サーバー送信なし・広告なし |
| キー | `niwatsumugi.v3` |
| 復元 | 起動時に両方を読み、**新しい方**を採用（IndexedDB が使えない環境でも動く） |
| 引越 | 設定 → 書き出す／読み込む（Base64 文字列。コピーして別ブラウザへ） |
| 初期化 | 設定 → すべて初期化（確認ダイアログあり） |

## 7. 同梱のツール（`dev/`）

ゲーム本体はファイル一つで、`dev/` は開発用の補助スクリプトです（遊むだけなら不要）。

```bash
node dev/check.js   # 構文・データ整合・三言語テキストの欠落チェック
node dev/smoke.js   # DOM を模した環境で 100 年ぶんシミュレート（約 5 秒）
node dev/shot.js garden   # Headless Chrome 用の確認画面を一時フォルダに生成
```

`smoke.js` は実際に 2400 日ぶんを回し、生育・交配・天候・出来事・勲章・保存の往復を検証します。
（このテストで「出来事が 1 件も発生しない」「初期苗床が開墾扱いになる」などの実バグが見つかりました。）

## 8. トラブルシューティング

- **黒い画面** — コンソールにエラーが出ています。`index.html` を最新にし、ブラウザを更新。
- **音が鳴らない** — 初回のタップ後に音が初期化されます。端末のマナーモード／音量も確認を。
- **日が進まない** — 「庭の速さ」が 本格 の場合、1 日は 3 時間です。PC 時計の大幅な変更は時間を混乱させます。
- **文字化け** — UTF-8（BOM なし）で保存し直す。
- **CDN が届かない環境** — 文字は OS 既定フォント、パーティクルは Canvas2D、音は Web Audio 直叩きに落ちますが、庭はそのまま育ちます（ネットワークを遮断して確認済み）。
